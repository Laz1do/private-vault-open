# 0.3.1：查找与原位复制

Windows 与 Chrome 扩展的文字、说明和操作按钮更清楚。密码列表中的每条普通记录直接提供“复制账号”和“复制密码”，无需先进入详情。搜索支持输入后即时筛选，也有可点击的“查找”按钮。

复制完成后，原按钮显示“已复制”；失败时显示“重试”。复制不会弹出成功浮层，也不会更改当前查看的记录。空字段无法复制，存在冲突的记录仍需打开详情选择具体版本。原 Ctrl K / Ctrl N 操作已移除，正常文本编辑、Tab 导航与 Escape 关闭弹窗继续可用。

导航保留同一块选中背景，在页面间连续移动；复制文字与勾选在原位置过渡。搜索结果即时显示，动画遵循系统的“减少动态效果”设置。动效理念参考 [onetake](https://github.com/feitangyuan/onetake) 的连续状态承接，由本项目自行使用 CSS 实现，没有引入其库或代码。

## 更新

1. 完成正在编辑的内容，退出托盘中的旧版软件，再运行新的 Windows 安装包。
2. Chrome 扩展使用新的 ZIP 内容替换原扩展目录，在 `chrome://extensions` 点击该扩展的重新加载按钮。使用客户端内置扩展目录时，先在新版软件中点击“打开扩展目录”刷新文件，再在 Chrome 重新加载。
3. 本版沿用现有密码库、`.pvault` 文件和服务器协议。Android 现有 0.2.0 安装包继续兼容，本次未发布 Android 新安装包。
